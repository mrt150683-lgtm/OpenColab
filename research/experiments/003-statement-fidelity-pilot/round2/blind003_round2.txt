T01
INFORMAL: Is there a $3$-uniform hypergraph on $n$ vertices which contains at least $n-O(1)$ different sizes of cliques (maximal complete subgraphs)? The answer is no, as proved by Gao [Ga25]: more generally, for any $k\geq 3$, every $k$-uniform hypergraph on $n$ vertices contains at most $n-f_k(n)$ different sizes of cliques, where $f_k(n)\to \infty$ as $n\to \infty$.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ¬ ∃ C : ℕ, ∀ᶠ n : ℕ in atTop, ∃ H : UniformHypergraph (Fin n) 3, n - C ≤ (UniformHypergraph.cliqueSizes H).ncard

T02
INFORMAL: Does every set $A \subseteq \mathbb{N}$ of positive density contain some finite $S \subset A$ such that $\sum_{n \in S} \frac{1}{n} = 1$? The answer is yes, proved by Bloom [Bl21] (even if 'positive density' is interpreted as 'positive upper density', which is likely what Erdős intended). The theorem below uses the positive-upper-density interpretation; the literal natural-density interpretation is recorded separately. This was formalized in Lean 3 by Bloom and Mehta.
FORMAL (Lean 4, Mathlib; text after the theorem name): : (∀ (A : Set ℕ), 0 ∉ A → 0 < A.upperDensity → ∃ (S : Finset ℕ), ↑S ⊆ A ∧ ∑ n ∈ S, (1 / n : ℚ) = 1)

T03
INFORMAL: Let $\hat{R}(G)$ denote the size Ramsey number, the minimal number of edges $m$ such that there is a graph $H$ with $m$ edges that is Ramsey for $G$. If $G$ has $n$ vertices and maximum degree $d$ then prove that $$\hat{R}(G)\ll_d n.$$ This was disproved for $d=3$ by Rödl and Szemerédi [RoSz00], who constructed a graph on $n$ vertices with maximum degree $3$ such that $\hat{R}(G)\gg n(\log n)^{c}$ for some absolute constant $c>0$.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ¬ ∃ C : ℝ, ∀ d : ℕ, ∀ (V : Type) [Fintype V] (G : SimpleGraph V), G.maxDegree ≤ d → (sizeRamsey G G : ℝ) ≤ C * Fintype.card V

T04
INFORMAL: If $G$ is a graph which contains odd cycles of $\leq k$ different lengths then $\chi(G)\leq 2k+2$, with equality if and only if $G$ contains $K_{2k+2}$. Conjectured by Bollobás and Erdős. Proved by Gyárfás [Gy92].
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ {V : Type*} (G : SimpleGraph V) (k : ℕ), G.oddCycleLengths.ncard ≤ k → G.chromaticNumber ≤ (2 * k + 2 : ℕ∞) ∧ (G.chromaticNumber = (2 * k + 2 : ℕ∞) ↔ (SimpleGraph.completeGraph (Fin (2 * k + 2))).IsContained G)

T05
INFORMAL: Does there exist $A = \{a_1 < a_2 < \cdots\} \subset \mathbb{N}$ which is a minimal basis of order $2$ (i.e. every large integer is the sum of $2$ elements from $A$, and no proper subset of $A$ has this property), such that $$\lim_{k\to\infty} \frac{a_k}{k^2} = c$$ for some $c \neq 0$? Erdős and Graham conjectured a negative answer to this question [ErGr80]. "Minimal basis of order $2$" is formalised as `Minimal` for the predicate `Set.IsAsymptoticAddBasisOfOrder · 2` on sets of naturals ordered by inclusion.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∃ (a : ℕ → ℕ), StrictMono a ∧ Minimal (fun A : Set ℕ ↦ A.IsAsymptoticAddBasisOfOrder 2) (Set.range a) ∧ ∃ (c : ℝ), c ≠ 0 ∧ Tendsto (fun n ↦ ((a n / n ^ 2 : ℕ) : ℝ)) atTop (𝓝 c)

T06
INFORMAL: The cochromatic number of $G$, denoted by $\zeta(G)$, is the minimum number of colours needed to colour the vertices of $G$ such that each colour class induces either a complete graph or empty graph. Is it true that if $G$ has no $K_5$ and $\zeta(G)\geq 4$ then $\chi(G) \leq \zeta(G)+2$? This has been disproved by Steiner [St24b], who constructed a graph $G$ with $\omega(G)=4$, $\zeta(G)=4$, and $\chi(G)=7$.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ¬ ∀ (V : Type*) [Fintype V] (G : SimpleGraph V), G.CliqueFree 5 → 4 ≤ G.cochromaticNumber → G.chromaticNumber ≤ G.cochromaticNumber + 2

T07
INFORMAL: Is there a constant $c > 0$ such that every graph on $2^n$ vertices with minimum degree $> (1-c) \cdot 2^n$ contains the $n$-dimensional hypercube $Q_n$? This is Erdős's question [Er93, p. 345]. See also [576] for the extremal number of edges that guarantee a $Q_n$.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∃ c > 0, ∀ n : ℕ, ∀ (G : SimpleGraph (Fin (2 ^ n))) [DecidableRel G.Adj], (∀ v, (G.degree v : ℝ) > (1 - c) * 2 ^ n) → (SimpleGraph.hypercube n).IsContained G

T08
INFORMAL: Is it true that, for every prime $p$, there is a prime $q \leq p$ which is a primitive root modulo $p$?
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ᵉ (p : ℕ) (hp_prime : p.Prime) (hp_nontrivial : p ≠ 2), ∃ q, q.Prime ∧ q < p ∧ orderOf (q : ZMod p) = p - 1

T09
INFORMAL: Does there exist an absolute constant $c>0$ such that, for all $r\geq 2$, in any $r$-uniform hypergraph with chromatic number $3$ there is a vertex contained in at least $(1+c)^r$ many edges? This was solved by Erdős and Lovász [ErLo75], who proved in particular that there is a vertex contained in at least $\frac{2^{r-1}}{4r}$ many edges.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∃ c : ℝ, 0 < c ∧ ∀ r : ℕ, 2 ≤ r → ∀ (n : ℕ) (H : Finset (Finset (Fin n))), H.IsUniform r → H.HasHypergraphChromaticNumber 3 → ∃ v : Fin n, 1 + c ^ r ≤ (H.hypergraphDegree v : ℝ)

T10
INFORMAL: Let $k\geq 3$. Does there exist a finite set $A\subset \mathbb{R}^2$ such that, in any $2$-colouring of $A$, there exists a line which contains at least $k$ points from $A$, and all the points of $A$ on the line have the same colour? Erdős [Er75f] says Graham and Selfridge proved the answer is yes when $k=3$. Hunter has observed that, for sufficiently large $n$, a generic projection of $[k]^n$ into $\mathbb{R}^2$ has this property, by the Hales-Jewett theorem.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ (k : ℕ), ∀ (hk : 3 ≤ k), ∃ (A : Finset (Fin 2 → ℝ)), ∀ (C : A → Fin 2), ∃ (S : Finset (Fin 2 → ℝ)), ∃ (hSA : S ⊆ A), Collinear ℝ (S : Set (Fin 2 → ℝ)) ∧ S.card ≥ k ∧ (∀ y ∈ A, y ∈ S → y ∈ affineSpan ℝ (S : Set (Fin 2 → ℝ))) ∧ ∃ c, ∀ x (hx : x ∈ S), C ⟨x, hSA hx⟩ = c

T11
INFORMAL: Erdős asks in [Er75b] if for every 2-coloring of ℝ, there is an uncountable set $A ⊆ ℝ$ such that all sums $a + b$ for $a, b ∈ A, a ≠ b$ have the same colour. In [Ko16] Péter Komjáth constructed a counterexample. The same result was proven independently in [SWCol] by Sokoup and Weiss.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ¬ ∀ f : ℝ → Fin 2, ∃ A : Set ℝ, A.Infinite ∧ ∀ᵉ (a ∈ A) (b ∈ A) (c ∈ A) (d ∈ A), a ≠ b → c ≠ d → f (a + b) = f (c + d)

T12
INFORMAL: If $n$ distinct points in $\mathbb{R}^2$ form a convex polygon then they determine at least $\lfloor \frac{n}{2}\rfloor$ distinct distances. Solved by Altman [Al63].
FORMAL (Lean 4, Mathlib; text after the theorem name): (A : Finset ℝ²) (hA : ConvexIndep (A : Set ℝ²)) : (A.card : ℝ) / 2 ≤ distinctDistances A

T13
INFORMAL: Is it true that, for all sufficiently large $n$, if $G$ is a triangle-free graph on $\{1,\ldots,n\}$ then there must exist three independent points $a,b,a+b$? A problem of Erdős and Hajnal [Er95d]. The stated problem has been resolved by Barber (personal communication) who verified using a SAT solver that this is true for all $n\geq 18$.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ᶠ n in atTop, ∀ G : SimpleGraph (Set.Icc 1 n), G.CliqueFree 3 → ∃ a b c : Set.Icc 1 n, a ≠ b ∧ (a : ℕ) + (b : ℕ) = c ∧ G.IsIndepSet {a, b, c}

T14
INFORMAL: Let $P(n)$ denote the largest prime factor of $n$. Show that the set of $n$ with $P(n+1) > P(n)$ has density $\frac{1}{2}$. This was proved by an internal OpenAI model in September 2026 [OAI26a]; see the linked Lean proof.
FORMAL (Lean 4, Mathlib; text after the theorem name): : { n | Nat.maxPrimeFac (n + 1) > Nat.maxPrimeFac n }.HasDensity (1/2)

T15
INFORMAL: Given any infinite set $A\subset \mathbb{N}$ there is a set $B$ of density $0$ such that $A+B$ contains all except finitely many integers. Conjectured by Erdős and Straus. Proved by Lorentz [Lo54].
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ A : Set ℕ, A.Infinite → ∃ B : Set ℕ, B.HasDensity 0 ∧ ∀ᶠ n in atTop, n ∈ A + B

T16
INFORMAL: Let $p_1,\ldots,p_k$ be distinct primes. Are there infinitely many $n$ such that $n!$ is divisible by an even power of each of the $p_i$? The answer is yes, proved by Berend [Be97], who further proved that the sequence of such $n$ has bounded gaps (where the bound depends on the initial set of primes).
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ S : Finset ℕ, (∀ p ∈ S, p.Prime) → {n : ℕ | ∀ p ∈ S, Even (padicValNat p (n !))}.Infinite

T17
INFORMAL: Let $x_1,\ldots,x_n\in\mathbb{R}^2$ determine the set of distances $\{u_1,\ldots,u_t\}$. Suppose $u_i$ appears as the distance between $f(u_i)$ many pairs of points. Then for all $\epsilon>0$ $$\sum_i f(u_i)^2 \ll_\epsilon n^{3+\epsilon}.$$ The case when the points determine a convex polygon was solved by Altman [Al63]. Note it is trivial that $\sum f(u_i)=\binom{n}{2}$. Solved by Guth and Katz [GuKa15] who proved the upper bound $$\sum_i f(u_i)^2 \ll n^3\log n.$$ See also [94](https://www.erdosproblems.com/94).
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ ε : ℝ, 0 < ε → ∃ C : ℝ, 0 < C ∧ ∀ P : Finset ℝ², ∑ u ∈ distanceSet P, (distanceMultiplicity P u : ℝ) ^ 2 ≤ C * (P.card : ℝ) ^ (3 + ε)

T18
INFORMAL: Let $Q_n$ be the $n$-dimensional hypercube graph (so that $Q_n$ has $2^n$ vertices and $n2^{n-1}$ edges). Prove that $$R(Q_n) \ll 2^n.$$
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∃ C > (0 : ℝ), ∀ n : ℕ, (diagonalGraphRamsey (hypercube n) : ℝ) ≤ C * 2 ^ n

T19
INFORMAL: Are there two infinite sets $A$ and $B$ such that $A+B$ agrees with the primes up to finitely many exceptions? This was disproved by an internal OpenAI model in September 2026 [OAI26a]; see the linked Lean proof.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ¬ ∃ A B : Set ℕ, A.Infinite ∧ B.Nonempty ∧ (A + B : Set ℕ) =ᶠ[Filter.cofinite] {n | n.Prime}

T20
INFORMAL: Let $C>0$ be a constant. Are there infinitely many integers $a,b,n$ with $a+b> n+C\log n$ such that the denominator of $$\frac{n!}{a!b!}$$contains only primes $\ll_C 1$? Erdős [Er68c] proved that if $a!b!\mid n!$ then $a+b\leq n+O(\log n)$. This has been proved in the affirmative by Barreto and Leeham, using ChatGPT and Aristotle, with a modification of the argument used for [728].
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ (C : ℝ) (hC : C > 0), ∃ K ≥ 3, Set.Infinite { T : ℕ × ℕ × ℕ | let (a, b, n) := T a > 0 ∧ b > 0 ∧ n > 0 ∧ (a : ℝ) + b > n + C * Real.log n ∧ ∀ p, p.Prime → p > K → padicValNat p (((n.factorial / (a.factorial * b.factorial) : ℕ) : ℚ).den) = 0 }

T21
INFORMAL: Is it true that in any finite colouring of $\mathbb{N}$ there exist arbitrarily large finite $A$ such that all sums and products of distinct elements in $A$ are the same colour?
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ (n : ℕ) (color : ℕ → Fin n) (m), ∃ (A : Finset ℕ), A.card ≥ m ∧ ∃ c, ∀ (S : Finset A), S.Nonempty → color (∑ x ∈ S, x) = c ∧ color (∏ x ∈ S, x) = c

T22
INFORMAL: Let $x,y\geq 1$ be integers such that, for all $n\geq 1$, the set of primes dividing $x^{n}-1$ is equal to the set of primes dividing $y^n-1$. Must $x=y$? Erdős asked this at a 1988 number theory conference in Banff. A positive answer was given by Corrales-Rodrigáñez and Schoof [CoSc97].
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ x y : ℕ, x ≥ 1 → y ≥ 1 → (∀ n : ℕ, n ≥ 1 → { p : ℕ | p.Prime ∧ p ∣ x ^ n - 1 } = { p : ℕ | p.Prime ∧ p ∣ y ^ n - 1 }) → x = y

T23
INFORMAL: Are there $n$ such that there is a covering system with moduli the divisors of $n$ which is 'as disjoint as possible'? That is, for all $d\mid n$ with $d>1$ there is an associated $a_d$ such that every integer is congruent to some $a_d\pmod{d}$, and if there is some integer $x$ with $$x\equiv a_d\pmod{d}\textrm{ and }x\equiv a_{d'}\pmod{d'}$$then $(d,d')=1$. The density of such $n$ is zero. Erdős and Graham believed that no such $n$ exist. Adenwalla [Ad25] has proved there are no such $n$. This was formalized by van Doorn in Lean using Aristotle.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ¬ ∃ (n : ℕ) (a : ℕ → ℤ), let D := {d : ℕ | d ∣ n ∧ d ≥ 1} (∀ x : ℤ, ∃ d ∈ D, x ≡ a d [ZMOD d]) ∧ (∀ d ∈ D, ∀ d' ∈ D, d ≠ d' → (∃ x : ℤ, x ≡ a d [ZMOD d] ∧ x ≡ a d' [ZMOD d']) → Nat.gcd d d' = 1)

T24
INFORMAL: Let $k\geq 3$. Is it true that, if $m$ is sufficiently large, for any graph $H$ on $m$ edges without isolated vertices, $$R(C_k,H) \leq 2m+\left\lfloor\frac{k-1}{2}\right\rfloor?$$ This was proved for even $k$ by Erdős, Faudree, Rousseau, and Schelp [EFRS93]. This was proved for $k=3$ independently by Goddard and Kleitman [GoKl94] and Sidorenko [Si91]. This was proved for $k=5$ by Jayawardene [Ja99]. Finally it was proved for all odd $k\geq 7$ by Cambie, Freschi, Morawski, Petrova, and Pokrovskiy [CFMPP26]. This problem is #35 in Ramsey Theory in the graphs problem collection.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ (k : ℕ) (hk : 3 ≤ k), ∀ᶠ (m : ℕ) in atTop, ∀ (W : Type) [Fintype W] (H : SimpleGraph W) [DecidableRel H.Adj], (∀ v, 0 < H.degree v) → H.edgeSet.ncard = m → SimpleGraph.graphRamsey (SimpleGraph.cycleGraph k) H ≤ 2 * m + k / 2

T25
INFORMAL: Is there a function $f$ with $f(n)\to\infty$ as $n\to\infty$ such that, for all large $n$, there is a composite number $m$ such that $$ n + f(n) < m < n + p(m) $$ Here $p(m)$ is the least prime factor of $m$.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∃ (f : ℕ → ℕ) (_ : Tendsto f atTop atTop), ∀ᶠ n in atTop, ∃ m, m.Composite ∧ n + f n < m ∧ m < n + n.minFac

T26
INFORMAL: If $G$ is a graph with infinite chromatic number and $a_1 < a_2 < \cdots$ are lengths of the odd cycles of $G$ then $\sum \frac{1}{a_i} = \infty$. Conjectured by Erdős and Hajnal [ErHa66], and solved by Liu and Montgomery [LiMo20]. The linked formal proof (Codex and GPT-5.6 Sol) states the conclusion as `¬ Summable (oddCycleReciprocal G)`, where `oddCycleReciprocal G n` is `n⁻¹` if `n` is an odd cycle length of `G` and `0` otherwise; this is the indicator form of the sum below.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ {V : Type*} (G : SimpleGraph V), G.chromaticNumber = ⊤ → ¬ Summable (fun (a : G.oddCycleLengths) ↦ ((1 / a : ℕ) : ℝ))

T27
INFORMAL: If ℕ is $2$-coloured then there must exist a monochromatic three-term arithmetic progression $x,x+d,x+2d$ such that $d>x$. This was first proved by Brown and Landman [BrLa99], who in fact show that this is always possible with $d>f(x)$ for any increasing function $f$. This was formalized in Lean by Alexeev using Aristotle and ChatGPT.
FORMAL (Lean 4, Mathlib; text after the theorem name): (c : ℕ → Bool) : ∃ x d, 0 < x ∧ x < d ∧ (∃ C, c x = C ∧ c (x + d) = C ∧ c (x + 2 * d) = C)

T28
INFORMAL: If $H$ is bipartite and is $r$-degenerate, that is, every induced subgraph of $H$ has minimum degree $\leq r$, then $$\mathrm{ex}(n;H) \ll n^{2-1/r}.$$ The answer is no. See `erdos_146.variants.two_degenerate_counterexample`.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ¬ ∀ (r q : ℕ) (H : SimpleGraph (Fin q)), 0 < r → H.IsBipartite → H.IsDegenerate r → Asymptotics.IsBigO atTop (fun n : ℕ => (extremalNumber n H : ℝ)) (fun n : ℕ => (n : ℝ) ^ ((2 - 1 / r : ℕ) : ℝ))

T30

Solved affirmatively following the work of Liu and Montgomery [LiMo20]. T31

T32

T38
INFORMAL: Is there some $h(n)\to \infty$ such that for all $2\leq i<j\leq n/2$ $$\textrm{gcd}\left( \binom{n}{i},\binom{n}{j}\right) \geq h(n)?$$ This was resolved by Bergman [Be11], who proved that for any $2\leq i<j\leq n/2$ $$\textrm{gcd}\left( \binom{n}{i},\binom{n}{j}\right) \gg n^{1/2}\frac{2^i}{i^{3/2}},$$ where the implied constant is absolute. The linked formal proof (van Doorn and Aristotle, see `erdos_698.variants.bergman`) gives the explicit bound $\gcd > \frac{2^i \sqrt n}{4 i \sqrt{i - 1}}$, so $h(n) = \lfloor \sqrt n / 4 \rfloor$ works since $i \sqrt{i - 1} \le 2^i$ for $i \ge 2$.
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∃ h : ℕ → ℕ, Tendsto h atTop atTop ∧ ∀ n i j : ℕ, 1 ≤ i → i < j → j ≤ n / 2 → h n ≤ Nat.gcd (n.choose i) (n.choose j)

FORMAL (Lean 4, Mathlib; text after the theorem name): : ¬ ∃ (x : ℕ → GaussianInt) (C : ℤ), Function.Injective x ∧ ∀ n, Prime (x n) ∧ (x (n + 1) - x n).norm < C

INFORMAL: Let $f:\mathbb{N}\to \{-1,1\}$ be a multiplicative function. Is it true that $$ \lim_{N\to \infty}\frac{1}{N}\sum_{n\leq N}f(n)$$ always exists? The answer is yes, as proved by Wirsing [Wi67], and generalised by Halász [Ha68].
FORMAL (Lean 4, Mathlib; text after the theorem name): : ∀ f : ℕ → ℝ, (∀ n ≥ 1, f n = 1 ∨ f n = -1) ∧ (∀ m n, m.Coprime n → f (m * n) = f m * f n) ∧ f 1 = 1 → ∃ L, Tendsto (fun N ↦ (∑ n ∈ Finset.Icc 1 N, f n) / N) atTop (𝓝 L)
