T01
INFORMAL: Is there a $3$-uniform hypergraph on $n$ vertices which contains at least $n-O(1)$ different sizes of cliques (maximal complete subgraphs)? The answer is no, as proved by Gao [Ga25]: more generally, for any $k\geq 3$, every $k$-uniform hypergraph on $n$ vertices contains at most $n-f_k(n)$ different sizes of cliques, where $f_k(n)\to \infty$ as $n\to \infty$.
TRANSLATION OF THE FORMAL STATEMENT: There is NO natural number C with the following property: for all sufficiently large natural n (eventually along atTop), there exists a 3-uniform hypergraph H on the vertex set Fin n = {0,...,n-1} such that n - C <= ncard(cliqueSizes H). Here n - C is truncated natural-number subtraction (equal to 0 when C >= n), and ncard is the cardinality of the set of clique sizes of H (the set of natural numbers that occur as sizes of cliques of H, per the definition UniformHypergraph.cliqueSizes); ncard would be 0 if that set were infinite (it is finite here since the vertex set is finite).

T02
INFORMAL: Does every set $A \subseteq \mathbb{N}$ of positive density contain some finite $S \subset A$ such that $\sum_{n \in S} \frac{1}{n} = 1$? The answer is yes, proved by Bloom [Bl21] (even if 'positive density' is interpreted as 'positive upper density', which is likely what Erdős intended). The theorem below uses the positive-upper-density interpretation; the literal natural-density interpretation is recorded separately. This was formalized in Lean 3 by Bloom and Mehta.
TRANSLATION OF THE FORMAL STATEMENT: (Asserted as true, not negated.) For every set A of natural numbers such that 0 is not in A and the upper density of A is strictly positive, there exists a finite set S of natural numbers with S a subset of A such that the sum over n in S of 1/n equals 1, where each n is cast to the rationals and 1/n is exact rational division (not truncated).

T03
INFORMAL: Let $\hat{R}(G)$ denote the size Ramsey number, the minimal number of edges $m$ such that there is a graph $H$ with $m$ edges that is Ramsey for $G$. If $G$ has $n$ vertices and maximum degree $d$ then prove that $$\hat{R}(G)\ll_d n.$$ This was disproved for $d=3$ by Rödl and Szemerédi [RoSz00], who constructed a graph on $n$ vertices with maximum degree $3$ such that $\hat{R}(G)\gg n(\log n)^{c}$ for some absolute constant $c>0$.
TRANSLATION OF THE FORMAL STATEMENT: There is NO real number C such that: for every natural d, every type V with a Fintype instance and every simple graph G on V, if the maximum degree of G is <= d then sizeRamsey(G, G) (cast to a real) <= C * |V| (the number of vertices, cast to a real). Quantifier order: C is chosen before d, so a single C must work for all d; since d is arbitrary the degree hypothesis imposes no real restriction, i.e. the statement says there is no constant C with sizeRamsey(G,G) <= C*|V| for all finite graphs G.

T04
INFORMAL: If $G$ is a graph which contains odd cycles of $\leq k$ different lengths then $\chi(G)\leq 2k+2$, with equality if and only if $G$ contains $K_{2k+2}$. Conjectured by Bollobás and Erdős. Proved by Gyárfás [Gy92].
TRANSLATION OF THE FORMAL STATEMENT: For every type V (any universe, not necessarily finite), every simple graph G on V and every natural k: if ncard(set of odd cycle lengths of G) <= k, then (i) the chromatic number of G (in extended naturals, possibly infinity) is <= 2k+2, and (ii) the chromatic number equals 2k+2 if and only if the complete graph on Fin(2k+2) is contained in G (as a subgraph copy, IsContained). Junk value caveat: ncard of an infinite set is 0, so if G has infinitely many distinct odd cycle lengths the hypothesis holds for every k, including k = 0.

T05
INFORMAL: Does there exist $A = \{a_1 < a_2 < \cdots\} \subset \mathbb{N}$ which is a minimal basis of order $2$ (i.e. every large integer is the sum of $2$ elements from $A$, and no proper subset of $A$ has this property), such that $$\lim_{k\to\infty} \frac{a_k}{k^2} = c$$ for some $c \neq 0$? Erdős and Graham conjectured a negative answer to this question [ErGr80]. "Minimal basis of order $2$" is formalised as `Minimal` for the predicate `Set.IsAsymptoticAddBasisOfOrder · 2` on sets of naturals ordered by inclusion.
TRANSLATION OF THE FORMAL STATEMENT: There exists a strictly increasing function a : N -> N such that (1) the range of a is a minimal set (with respect to inclusion: no proper subset has the property) among sets of naturals satisfying IsAsymptoticAddBasisOfOrder 2 (asymptotic additive basis of order 2), and (2) there is a real c != 0 such that the sequence n |-> ((a n / n^2 : N) cast to R) tends to c as n -> infinity. Important: a n / n^2 is computed in the natural numbers with truncating (floor) division before being cast to R (and at n = 0 it is a 0 / 0 = 0). Since the sequence takes integer values, convergence to c != 0 means floor(a n / n^2) is eventually equal to a fixed positive integer c.

T06
INFORMAL: The cochromatic number of $G$, denoted by $\zeta(G)$, is the minimum number of colours needed to colour the vertices of $G$ such that each colour class induces either a complete graph or empty graph. Is it true that if $G$ has no $K_5$ and $\zeta(G)\geq 4$ then $\chi(G) \leq \zeta(G)+2$? This has been disproved by Steiner [St24b], who constructed a graph $G$ with $\omega(G)=4$, $\zeta(G)=4$, and $\chi(G)=7$.
TRANSLATION OF THE FORMAL STATEMENT: It is NOT the case that: for every type V with Fintype instance and every simple graph G on V, if G is K5-free (CliqueFree 5: no clique of size 5) and 4 <= cochromatic number of G, then chromatic number of G <= cochromatic number of G + 2. Equivalently, there exists a finite graph G that has no 5-clique, has cochromatic number >= 4, and has chromatic number > cochromatic number + 2 (comparisons in the extended naturals / the types of these invariants).

T07
INFORMAL: Is there a constant $c > 0$ such that every graph on $2^n$ vertices with minimum degree $> (1-c) \cdot 2^n$ contains the $n$-dimensional hypercube $Q_n$? This is Erdős's question [Er93, p. 345]. See also [576] for the extremal number of edges that guarantee a $Q_n$.
TRANSLATION OF THE FORMAL STATEMENT: There exists c > 0 (a real, since it multiplies a real) such that for every natural n and every simple graph G on the vertex set Fin(2^n) (with decidable adjacency): if every vertex v has degree (cast to R) strictly greater than (1 - c) * 2^n (real arithmetic), then the n-dimensional hypercube graph Q_n is contained in G (IsContained: G has a subgraph isomorphic to Q_n). Note c is fixed before n.

T08
INFORMAL: Is it true that, for every prime $p$, there is a prime $q \leq p$ which is a primitive root modulo $p$?
TRANSLATION OF THE FORMAL STATEMENT: For every natural p that is prime and p != 2, there exists a natural q such that q is prime, q < p, and the multiplicative order of q (cast into ZMod p) equals p - 1 (natural subtraction; no truncation since p >= 3). I.e. every odd prime p has a prime primitive root smaller than p.

T09
INFORMAL: Does there exist an absolute constant $c>0$ such that, for all $r\geq 2$, in any $r$-uniform hypergraph with chromatic number $3$ there is a vertex contained in at least $(1+c)^r$ many edges? This was solved by Erdős and Lovász [ErLo75], who proved in particular that there is a vertex contained in at least $\frac{2^{r-1}}{4r}$ many edges.
TRANSLATION OF THE FORMAL STATEMENT: There exists a real c > 0 such that for every natural r >= 2, every natural n and every family H of finite subsets of Fin n: if H is r-uniform (every edge has exactly r elements) and H has hypergraph chromatic number 3 (HasHypergraphChromaticNumber 3, per its definition), then there is a vertex v in Fin n whose degree in H (number of edges containing v, cast to R) is >= 1 + c^r. Note the bound is 1 + c^r (c raised to r, plus 1), not (1+c)^r. Since c is fixed first, it must work for all r. (If n = 0 no vertex exists, so the conclusion requires the hypothesis to fail there.)

T10
INFORMAL: Let $k\geq 3$. Does there exist a finite set $A\subset \mathbb{R}^2$ such that, in any $2$-colouring of $A$, there exists a line which contains at least $k$ points from $A$, and all the points of $A$ on the line have the same colour? Erdős [Er75f] says Graham and Selfridge proved the answer is yes when $k=3$. Hunter has observed that, for sufficiently large $n$, a generic projection of $[k]^n$ into $\mathbb{R}^2$ has this property, by the Hales-Jewett theorem.
TRANSLATION OF THE FORMAL STATEMENT: For every natural k >= 3, there exists a finite set A of points of R^2 (modelled as Fin 2 -> R) such that for every 2-coloring C : A -> Fin 2 there exists a finite set S of points with S a subset of A, S collinear, |S| >= k, the condition (for all y in A, y in S -> y in affineSpan(S)) which is trivially true since every point of S lies in its own affine span (so it does NOT require S to contain all points of A on the line), and a color c such that every x in S has C(x) = c. Effectively: some k collinear points of A are monochromatic.

T11
INFORMAL: Erdős asks in [Er75b] if for every 2-coloring of ℝ, there is an uncountable set $A ⊆ ℝ$ such that all sums $a + b$ for $a, b ∈ A, a ≠ b$ have the same colour. In [Ko16] Péter Komjáth constructed a counterexample. The same result was proven independently in [SWCol] by Sokoup and Weiss.
TRANSLATION OF THE FORMAL STATEMENT: It is NOT the case that for every function f : R -> Fin 2 (2-coloring of the reals) there exists an infinite set A of reals such that for all a, b, c, d in A with a != b and c != d, f(a+b) = f(c+d). Equivalently: there is a 2-coloring of R such that no infinite set A has all sums of two distinct elements of the same color.

T12
INFORMAL: If $n$ distinct points in $\mathbb{R}^2$ form a convex polygon then they determine at least $\lfloor \frac{n}{2}\rfloor$ distinct distances. Solved by Altman [Al63].
TRANSLATION OF THE FORMAL STATEMENT: For every finite set A of points in the plane R^2 (Euclidean plane) that is convex independent (ConvexIndep: no point of A lies in the convex hull of the other points, per the definition), |A| / 2 <= distinctDistances A, where |A| is cast to R and divided by 2 in the reals (no truncation), and distinctDistances A is the number of distinct distances determined by pairs of points of A (as defined; whether distance 0 is counted depends on that definition), compared as a real.

T13
INFORMAL: Is it true that, for all sufficiently large $n$, if $G$ is a triangle-free graph on $\{1,\ldots,n\}$ then there must exist three independent points $a,b,a+b$? A problem of Erdős and Hajnal [Er95d]. The stated problem has been resolved by Barber (personal communication) who verified using a SAT solver that this is true for all $n\geq 18$.
TRANSLATION OF THE FORMAL STATEMENT: For all sufficiently large natural n, for every simple graph G whose vertex set is the set {1, 2, ..., n} (Set.Icc 1 n, both endpoints included): if G is triangle-free (CliqueFree 3), then there exist a, b, c in {1,...,n} with a != b, a + b = c (as naturals), and {a, b, c} is an independent set of G (no edge of G joins two of them). (c differs from a and b automatically since a, b >= 1.)

T14
INFORMAL: Let $P(n)$ denote the largest prime factor of $n$. Show that the set of $n$ with $P(n+1) > P(n)$ has density $\frac{1}{2}$. This was proved by an internal OpenAI model in September 2026 [OAI26a]; see the linked Lean proof.
TRANSLATION OF THE FORMAL STATEMENT: The set of natural numbers n such that Nat.maxPrimeFac(n+1) > Nat.maxPrimeFac(n) (largest prime factor; the values at 0 and 1 are whatever junk values the definition assigns) has natural (asymptotic) density exactly 1/2.

T15
INFORMAL: Given any infinite set $A\subset \mathbb{N}$ there is a set $B$ of density $0$ such that $A+B$ contains all except finitely many integers. Conjectured by Erdős and Straus. Proved by Lorentz [Lo54].
TRANSLATION OF THE FORMAL STATEMENT: For every infinite set A of natural numbers, there exists a set B of natural numbers with natural density 0 such that every sufficiently large natural n belongs to the sumset A + B = {a + b : a in A, b in B}.

T16
INFORMAL: Let $p_1,\ldots,p_k$ be distinct primes. Are there infinitely many $n$ such that $n!$ is divisible by an even power of each of the $p_i$? The answer is yes, proved by Berend [Be97], who further proved that the sequence of such $n$ has bounded gaps (where the bound depends on the initial set of primes).
TRANSLATION OF THE FORMAL STATEMENT: For every finite set S of natural numbers all of whose elements are prime, the set of natural numbers n such that for every p in S the p-adic valuation of n! is even is an infinite set. (S may be empty, in which case the condition is vacuous.)

T17
INFORMAL: Let $x_1,\ldots,x_n\in\mathbb{R}^2$ determine the set of distances $\{u_1,\ldots,u_t\}$. Suppose $u_i$ appears as the distance between $f(u_i)$ many pairs of points. Then for all $\epsilon>0$ $$\sum_i f(u_i)^2 \ll_\epsilon n^{3+\epsilon}.$$ The case when the points determine a convex polygon was solved by Altman [Al63]. Note it is trivial that $\sum f(u_i)=\binom{n}{2}$. Solved by Guth and Katz [GuKa15] who proved the upper bound $$\sum_i f(u_i)^2 \ll n^3\log n.$$ See also [94](https://www.erdosproblems.com/94).
TRANSLATION OF THE FORMAL STATEMENT: For every real eps > 0 there exists a real C > 0 such that for every finite set P of points in R^2: the sum, over all u in distanceSet P (the set of distances determined by P, per its definition), of (distanceMultiplicity P u)^2 (the number of pairs at distance u, per its definition, cast to R, squared) is <= C * |P|^(3 + eps), where |P| is cast to R and the exponent is a real power. C depends on eps only.

T18
INFORMAL: Let $Q_n$ be the $n$-dimensional hypercube graph (so that $Q_n$ has $2^n$ vertices and $n2^{n-1}$ edges). Prove that $$R(Q_n) \ll 2^n.$$
TRANSLATION OF THE FORMAL STATEMENT: There exists a real C > 0 such that for every natural n, the diagonal Ramsey number of the n-dimensional hypercube graph Q_n (diagonalGraphRamsey(hypercube n), i.e. R(Q_n, Q_n), cast to R) is <= C * 2^n.

T19
INFORMAL: Are there two infinite sets $A$ and $B$ such that $A+B$ agrees with the primes up to finitely many exceptions? This was disproved by an internal OpenAI model in September 2026 [OAI26a]; see the linked Lean proof.
TRANSLATION OF THE FORMAL STATEMENT: There do NOT exist sets A, B of natural numbers with A infinite and B nonempty such that the sumset A + B is eventually equal, along the cofinite filter, to the set of primes, i.e. A + B and the set of primes differ in only finitely many elements (finite symmetric difference).

T20
INFORMAL: Let $C>0$ be a constant. Are there infinitely many integers $a,b,n$ with $a+b> n+C\log n$ such that the denominator of $$\frac{n!}{a!b!}$$contains only primes $\ll_C 1$? Erdős [Er68c] proved that if $a!b!\mid n!$ then $a+b\leq n+O(\log n)$. This has been proved in the affirmative by Barreto and Leeham, using ChatGPT and Aristotle, with a modification of the argument used for [728].
TRANSLATION OF THE FORMAL STATEMENT: For every real C > 0 there exists a natural K >= 3 such that the set of triples (a, b, n) of natural numbers satisfying all of: a > 0, b > 0, n > 0, (a + b as a real) > n + C * log n (natural log, real arithmetic), and for every prime p > K, the p-adic valuation of the denominator of the rational number obtained by casting to Q the NATURAL number n! / (a! * b!) (truncating natural floor division) equals 0 -- is infinite. Note: because the quotient is computed in N and then cast to Q, it is an integer, so its denominator is 1 and the valuation condition holds automatically; thus the statement only requires infinitely many positive triples with a + b > n + C log n.

T21
INFORMAL: Is it true that in any finite colouring of $\mathbb{N}$ there exist arbitrarily large finite $A$ such that all sums and products of distinct elements in $A$ are the same colour?
TRANSLATION OF THE FORMAL STATEMENT: For every natural n, every coloring color : N -> Fin n, and every natural m, there exists a finite set A of natural numbers with |A| >= m and a color c such that for every nonempty finite subset S of A (a Finset of the subtype A), color(sum of the elements of S) = c and color(product of the elements of S) = c. (A may contain 0 or 1; for n = 0 there is no coloring, so it holds vacuously.)

T22
INFORMAL: Let $x,y\geq 1$ be integers such that, for all $n\geq 1$, the set of primes dividing $x^{n}-1$ is equal to the set of primes dividing $y^n-1$. Must $x=y$? Erdős asked this at a 1988 number theory conference in Banff. A positive answer was given by Corrales-Rodrigáñez and Schoof [CoSc97].
TRANSLATION OF THE FORMAL STATEMENT: For all natural x, y with x >= 1 and y >= 1: if for every natural n >= 1 the set of primes p dividing x^n - 1 equals the set of primes p dividing y^n - 1 (natural subtraction, which does not truncate here since x^n, y^n >= 1; note when x = 1, x^n - 1 = 0 and every prime divides 0), then x = y.

T23
INFORMAL: Are there $n$ such that there is a covering system with moduli the divisors of $n$ which is 'as disjoint as possible'? That is, for all $d\mid n$ with $d>1$ there is an associated $a_d$ such that every integer is congruent to some $a_d\pmod{d}$, and if there is some integer $x$ with $$x\equiv a_d\pmod{d}\textrm{ and }x\equiv a_{d'}\pmod{d'}$$then $(d,d')=1$. The density of such $n$ is zero. Erdős and Graham believed that no such $n$ exist. Adenwalla [Ad25] has proved there are no such $n$. This was formalized by van Doorn in Lean using Aristotle.
TRANSLATION OF THE FORMAL STATEMENT: There do NOT exist a natural n and a function a : N -> Z such that, with D := {d in N : d divides n and d >= 1}: (1) every integer x satisfies x == a(d) (mod d) for some d in D, and (2) for all d, d' in D with d != d', if some integer x satisfies both x == a(d) (mod d) and x == a(d') (mod d'), then gcd(d, d') = 1. (n = 0 is allowed, in which case D is all positive naturals. Note as written: for n = 1, D = {1}, every integer is congruent to a(1) mod 1, and (2) is vacuous, so such n and a do exist and the negated statement as written is false.)

T24
INFORMAL: Let $k\geq 3$. Is it true that, if $m$ is sufficiently large, for any graph $H$ on $m$ edges without isolated vertices, $$R(C_k,H) \leq 2m+\left\lfloor\frac{k-1}{2}\right\rfloor?$$ This was proved for even $k$ by Erdős, Faudree, Rousseau, and Schelp [EFRS93]. This was proved for $k=3$ independently by Goddard and Kleitman [GoKl94] and Sidorenko [Si91]. This was proved for $k=5$ by Jayawardene [Ja99]. Finally it was proved for all odd $k\geq 7$ by Cambie, Freschi, Morawski, Petrova, and Pokrovskiy [CFMPP26]. This problem is #35 in Ramsey Theory in the graphs problem collection.
TRANSLATION OF THE FORMAL STATEMENT: For every natural k >= 3, for all sufficiently large natural m, for every finite type W and simple graph H on W (decidable adjacency) such that every vertex has positive degree (no isolated vertices) and the edge set of H has exactly m elements (ncard), the graph Ramsey number graphRamsey(C_k, H) (C_k = cycle graph on k vertices) is <= 2m + k/2, where k/2 is truncating natural division (floor(k/2)), and all arithmetic is in N.

T25
INFORMAL: Is there a function $f$ with $f(n)\to\infty$ as $n\to\infty$ such that, for all large $n$, there is a composite number $m$ such that $$ n + f(n) < m < n + p(m) $$ Here $p(m)$ is the least prime factor of $m$.
TRANSLATION OF THE FORMAL STATEMENT: There exists a function f : N -> N with f(n) -> infinity as n -> infinity such that for all sufficiently large n there exists a composite natural m with n + f(n) < m < n + minFac(n) (strict inequalities; minFac(n) is the smallest prime factor of n, with junk values minFac 0 = 2, minFac 1 = 1).

T26
INFORMAL: If $G$ is a graph with infinite chromatic number and $a_1 < a_2 < \cdots$ are lengths of the odd cycles of $G$ then $\sum \frac{1}{a_i} = \infty$. Conjectured by Erdős and Hajnal [ErHa66], and solved by Liu and Montgomery [LiMo20]. The linked formal proof (Codex and GPT-5.6 Sol) states the conclusion as `¬ Summable (oddCycleReciprocal G)`, where `oddCycleReciprocal G n` is `n⁻¹` if `n` is an odd cycle length of `G` and `0` otherwise; this is the indicator form of the sum below.
TRANSLATION OF THE FORMAL STATEMENT: For every type V and every simple graph G on V: if the chromatic number of G is infinite (= top in extended naturals), then the function on the set of odd cycle lengths of G, a |-> ((1 / a : N) cast to R), is NOT summable. Important: 1 / a is truncating natural division, equal to 0 for every a >= 2 (and 1 only if a = 1). Since odd cycle lengths in a simple graph are >= 3, every term is 0, the family is summable, and the conclusion is false; as written the statement thus asserts that no simple graph has infinite chromatic number.

T27
INFORMAL: If ℕ is $2$-coloured then there must exist a monochromatic three-term arithmetic progression $x,x+d,x+2d$ such that $d>x$. This was first proved by Brown and Landman [BrLa99], who in fact show that this is always possible with $d>f(x)$ for any increasing function $f$. This was formalized in Lean by Alexeev using Aristotle and ChatGPT.
TRANSLATION OF THE FORMAL STATEMENT: For every function c : N -> Bool (2-coloring of the naturals), there exist natural numbers x and d with 0 < x < d such that c(x), c(x+d), c(x+2d) are all equal (to some common value C). Note d must exceed x.

T28
INFORMAL: If $H$ is bipartite and is $r$-degenerate, that is, every induced subgraph of $H$ has minimum degree $\leq r$, then $$\mathrm{ex}(n;H) \ll n^{2-1/r}.$$ The answer is no. OpenAI [OpenAI26] give a connected bipartite `2`-degenerate `H` and constants `c, ε > 0` with $\mathrm{ex}(n;H)\geq cn^{3/2+\epsilon}$ for all large `n`, which exceeds the conjectured $n^{2-1/2}=n^{3/2}$. See `erdos_146.variants.two_degenerate_counterexample`.
TRANSLATION OF THE FORMAL STATEMENT: It is NOT the case that: for all naturals r, q and every simple graph H on Fin q, if r > 0, H is bipartite and H is r-degenerate, then the function n |-> extremalNumber n H (cast to R) is Big-O (as n -> infinity) of n |-> n^e (real power), where e is the cast to R of the NATURAL number 2 - 1/r with 1/r truncating natural division and the subtraction truncating. So e = 1 when r = 1 and e = 2 when r >= 2 (not 2 - 1/r as a real). The statement asserts that some r > 0 and bipartite r-degenerate H exist for which ex(n, H) is not O(n^e).

T29
INFORMAL: We call a graph $D$-balanced (or $D$-almost-regular) if the maximum degree is at most $D$ times the minimum degree. Let $ε, α > 0$ and $D$ and $n$ be sufficiently large. If $G$ is a graph on $n$ vertices with at least $n^{1+α}$ edges, then must $G$ contain a $D$-balanced subgraph on $m > n^{1-α}$ vertices with at least $εm^{1+α}$ edges?
TRANSLATION OF THE FORMAL STATEMENT: It is NOT the case that: for every real eps with 0 < eps < 1 and every real alpha with 0 < alpha < 1, for all sufficiently large D (eventually in atTop), for all sufficiently large natural n (eventually, with the threshold allowed to depend on D), for every simple graph G on Fin n with number of edges (ncard, as a real) > n^(1+alpha), there exists a subgraph H of G such that, with m := number of vertices of H (ncard), H (as a graph on its vertex subtype) is D-balanced (IsBalanced, per its definition), m > n^(1-alpha), and the number of edges of H > eps * m^(1+alpha) (real powers). Quantifier order: eps, alpha, then eventually D, then eventually n.

T30
INFORMAL: Does every graph with infinite chromatic number contain a cycle of length $2^n$ for infinitely many $n$? Conjectured by Mihók and Erdős. Solved affirmatively following the work of Liu and Montgomery [LiMo20]. The linked formal proof (Codex) states the conclusion as `{n | HasCycleLength G (2 ^ n)}.Infinite`, with `HasCycleLength G m` unfolding to `m ∈ G.cycleLengths`.
TRANSLATION OF THE FORMAL STATEMENT: For every type V and every simple graph G on V with infinite chromatic number (= top), for every natural N there exists a natural n >= N such that 2^n belongs to the set of cycle lengths of G; i.e. G contains cycles of length 2^n for infinitely many n.

T31
INFORMAL: We say $G$ is Ramsey size linear if $R(G,H)\ll m$ for all graphs $H$ with $m$ edges and no isolated vertices. Are there infinitely many graphs $G$ which are not Ramsey size linear but such that all of its proper subgraphs are? Asked by Erdős, Faudree, Rousseau, and Schelp [EFRS93]. $K_4$ was long the only known example. Wigderson [Wi24] proved that there are infinitely many such graphs.
TRANSLATION OF THE FORMAL STATEMENT: For every natural N there exist a natural n >= N and a simple graph G on Fin n such that G is NOT Ramsey size linear (IsRamseySizeLinear, per its definition), but every subgraph H of G with H strictly less than the top subgraph (i.e. every proper subgraph: missing at least one vertex or at least one edge), viewed as a graph on its vertex subtype, IS Ramsey size linear.

T32
INFORMAL: If $T$ is a tree on $n$ vertices then $$R(T) \leq 2n-2.$$ This problem is #14 in Ramsey Theory in the graphs problem collection. Solved: the bound follows from the Erdős–Sós theorem (Erdős problem 548) by the pigeonhole principle, as noted on the problem page.
TRANSLATION OF THE FORMAL STATEMENT: For every natural n >= 2 and every simple graph T on Fin n that is a tree, the diagonal Ramsey number R(T, T) (diagonalGraphRamsey T) is <= 2n - 2 (natural subtraction; no truncation since n >= 2).

T33
INFORMAL: Let $A$ be a finite set of integers such that $\lvert A+A\rvert \ll \lvert A\rvert$. Is it true that $$\lvert AA\rvert \gg \frac{\lvert A\rvert^2}{(\log \lvert A\rvert)^C}$$ for some constant $C>0$? This was proved by Solymosi [So09d], in the strong form $$\lvert AA\rvert \gg \frac{\lvert A\rvert^2}{\log \lvert A\rvert}.$$ See also [52].
TRANSLATION OF THE FORMAL STATEMENT: For every real K > 0 there exist reals C > 0 and c > 0 such that for every finite set A of integers with |A| >= 2 and |A + A| <= K * |A|^2 (cardinalities cast to R): c * |A|^2 / (log |A|)^C <= |A * A|, where A + A is the sumset, A * A the product set, log the natural logarithm, the power (log|A|)^C a real power, and division real. (Note |A+A| <= |A|^2 always, so for K >= 1 the second hypothesis is automatic.)

T34
INFORMAL: Let $a_n$ be an infinite sequence of positive integers such that $\sum \frac{1}{a_n}$ converges. There exists some integer $t \ge 1$ such that $\sum \frac{1}{a_n + t}$ is irrational. This was disproven by Kovač and Tao in [KoTa24]. [KoTa24] Kovač, V. and Tao T., On several irrationality problems for Ahmes series. [arXiv:2406.17593](https://arxiv.org/abs/2406.17593) (2024).
TRANSLATION OF THE FORMAL STATEMENT: It is NOT the case that for every a : N -> N: if (a(n) >= 1 for all natural n, including n = 0) and (the real sequence n |-> 1/a(n) is summable), then there exists a real t >= 1 such that the (unconditional) sum over all n of 1/(a(n) + t) (real division) is irrational. Equivalently: there is a sequence of positive integers with summable reciprocals such that for every real t >= 1, the sum of 1/(a(n)+t) is rational (this sum converges by comparison, so no tsum junk value arises).

T38
INFORMAL: Is there some $h(n)\to \infty$ such that for all $2\leq i<j\leq n/2$ $$\textrm{gcd}\left( \binom{n}{i},\binom{n}{j}\right) \geq h(n)?$$ This was resolved by Bergman [Be11], who proved that for any $2\leq i<j\leq n/2$ $$\textrm{gcd}\left( \binom{n}{i},\binom{n}{j}\right) \gg n^{1/2}\frac{2^i}{i^{3/2}},$$ where the implied constant is absolute. The linked formal proof (van Doorn and Aristotle, see `erdos_698.variants.bergman`) gives the explicit bound $\gcd > \frac{2^i \sqrt n}{4 i \sqrt{i - 1}}$, so $h(n) = \lfloor \sqrt n / 4 \rfloor$ works since $i \sqrt{i - 1} \le 2^i$ for $i \ge 2$.
TRANSLATION OF THE FORMAL STATEMENT: There exists a function h : N -> N with h(n) -> infinity such that for all naturals n, i, j with 1 <= i < j <= n / 2 (n / 2 is truncating natural division, floor(n/2)), h(n) <= gcd(C(n, i), C(n, j)) (binomial coefficients). For n with no such pair i, j (n < 4) the condition is vacuous.

T39
INFORMAL: Is there an infinite sequence of distinct Gaussian primes $x_1,x_2,\ldots$ such that $\lvert x_{n+1}-x_n\rvert \ll 1$? No. This was disproved by an internal OpenAI model in September 2026 [OAI26a]; see the linked Lean proof.
TRANSLATION OF THE FORMAL STATEMENT: There do NOT exist a sequence x : N -> Gaussian integers Z[i] and an integer C such that x is injective and, for every n, x(n) is a prime element of Z[i] (Prime in the ring sense) and the norm of x(n+1) - x(n) (the integer a^2 + b^2) is < C. I.e. one cannot walk through infinitely many distinct Gaussian primes with uniformly bounded steps.
